# MJ Rahman — Portfolio

Personal portfolio website of MJ Rahman, graphic designer and brand builder based in Vancouver, BC.

## Publish with GitHub Pages
1. Create a new public repository (name it `yourusername.github.io` to get the address `https://yourusername.github.io`).
2. Upload everything in this folder, keeping the `assets` folder structure as it is.
3. Open the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site goes live in a minute or two.

## Folder structure
- `index.html` — the whole site (styles and scripts included)
- `assets/img/` — portrait, cloud portrait and elevator images
- `assets/img/work/` — the 15 project images
- `assets/fonts/` — Anton, Caveat and Instrument Sans (SIL Open Font License)

## Editing
- Replace a project image by saving a new file with the same name in `assets/img/work/`.
- Project titles and descriptions are in the `WORK` list near the bottom of `index.html`.
